# 📱 MikroTik Mobile Scanner v2.0 (PWA)

**تطبيق ويب متنقل** لفحص كروت MikroTik يعمل على الهاتف بدون سيرفر.

## ✨ المميزات

| الميزة | الوصف |
|--------|-------|
| 📱 **PWA** | يعمل كتطبيق حقيقي على الشاشة الرئيسية |
| 🌐 **CORS Proxy** | يتجاوز حظر المتصفح عبر Proxy مجاني |
| 💾 **IndexedDB** | تخزين محلي دائم على الهاتف |
| 🔍 **GET/POST** | يدعم جميع طرق الإرسال |
| ⏱️ **تأخير عشوائي** | تجنب الحظر |
| 🔄 **Offline** | يعمل بدون إنترنت للواجهة |

## 🚀 التثبيت

### الطريقة 1: GitHub Pages (مجاني)
1. ارفع الملفات إلى مستودع GitHub
2. فعّل GitHub Pages من الإعدادات
3. افتح الرابط على الهاتف
4. اضغط "Add to Home Screen"

### الطريقة 2: سيرفر محلي
```bash
# استخدم Python
python -m http.server 8080

# أو Node.js
npx serve .
```

### الطريقة 3: Netlify/Vercel (مجاني)
1. اسحب الملفات إلى Netlify Drop
2. احصل على رابط فوري

## 🔌 CORS Proxy المستخدم

- **corsproxy.io** (افتراضي) - 60 طلب/دقيقة مجاناً
- **cors.sh** - بديل
- **allorigins.win** - بديل

## ⚠️ تحذير

- CORS Proxy يقرأ البيانات المرسلة. لا تستخدمه لبيانات حساسة.
- للاستخدام القانوني فقط على شبكات تملكها.
